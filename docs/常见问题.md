# 常见问题

做实验时碰到的问题，记下来省得下次再查。

## 1. git push 报 Permission denied (publickey)

多数是公钥没加到 GitHub。先试：

```bash
ssh -T git@github.com
```

正常会显示 `Hi 用户名! You've successfully authenticated`。如果还是 denied，去 GitHub 的 Settings → SSH and GPG keys 看看那把 key 在不在。

## 2. 推送被拒：failed to push some refs

常见原因是远程仓库建的时候勾了 README，本地和远程都有提交，对不上。先拉再推：

```bash
git pull --rebase origin main
git push
```

## 3. reset 之后提交不见了

没丢。`git reflog` 里能找到它，复制前面的编号，`git reset --hard 编号` 就回来了。真正救不回来的是从来没提交过的改动。

## 4. 中文文件名显示成乱码

Windows 上把 git 的编码设置一下：

```bash
git config --global core.quotepath false
```

## 5. 每次都要输入密码

说明用的是 https 地址而不是 ssh。换成 ssh 地址即可：

```bash
git remote set-url origin git@github.com:用户名/仓库名.git
```
