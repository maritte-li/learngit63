# Git 常用命令速查

这里记的是这门课用到的命令，按使用顺序排，不是完整的命令手册。

## 一、看状态

```bash
git status            # 当前在哪个分支、哪些文件改了
git diff              # 工作区改了什么（没 add 之前看）
git diff --staged     # 暂存区里有什么（add 之后看）
git log --oneline     # 一行一个版本
```

`git status` 是最常用的，改完文件先敲一下，心里有数再往下走。

## 二、提交

```bash
git add test2025131063.txt    # 把改动放进暂存区
git commit -m "说明"           # 生成一个版本
```

`add` 和 `commit` 是两步，不能合并。`add` 只是挑出这次要提交什么，`commit` 才真正存下来。

## 三、回退与找回

```bash
git reset --hard HEAD^        # 回到上一个版本（工作区一起改）
git reset --hard <commit_id>  # 回到指定版本
git reflog                    # 看所有 HEAD 移动记录
```

`reset --hard` 会丢掉没提交的改动，用之前先 `git status` 看一眼。手滑了也不要紧，`git reflog` 里能找到刚才那个版本号，再 reset 回去。

## 四、分支

```bash
git branch                    # 查看分支
git branch <name>             # 创建分支
git switch <name>             # 切换分支
git switch -c <name>          # 创建并切换
git merge <name>              # 把某个分支合并到当前分支
git branch -d <name>          # 删除已合并的分支
```

`git switch` 是新的写法，比 `git checkout` 好记：`checkout` 既能切分支又能撤销文件，容易混。

## 五、远程

```bash
git remote add origin git@github.com:用户名/仓库名.git
git push -u origin main       # 第一次推，顺便记住关联
git push                      # 以后直接推
git clone <地址>              # 把远程仓库完整拉下来
```

第一次连 GitHub 会问 `Are you sure you want to continue connecting`，输 `yes` 就行，之后不再问。
