# learngit63

一个用来练习 Git 和开源协作流程的小仓库。名字里的 **63** 是我学号（2025131063）的后两位。

仓库里放了两样东西：一份自己整理的 Git 常用命令速查，和这门课做实验时留下的记录。

## 仓库里有什么

```
learngit63/
├── README.md              项目说明（就是这个文件）
├── LICENSE                MIT 许可证
├── test2025131063.txt     实验用文本，内容从 111 改到 222
├── file2025131063.txt     删除实验用的文件
└── docs/
    ├── 命令速查.md        常用命令和解释
    ├── 常见问题.md        踩过的坑
    └── 开发日志.md        每次改动的记录（分支冲突就是在这里演示的）
```

## 怎么用

把仓库拉到本地：

```bash
git clone git@github.com:maritte-li/learngit63.git
cd learngit63
```

`docs/命令速查.md` 里的命令可以直接照着敲，都是我在自己电脑上验证过的。

## 关于许可证

用的是 MIT 许可证。选它的原因很简单：短、好懂，别人拿去用、改、再发布都可以，只要保留版权声明就行。对一个小仓库来说，这已经够用了。
